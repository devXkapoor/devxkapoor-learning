The chain in one paragraph

A wire is either carrying electricity or not, and binary won over decimal because noise is then thrown away at every step instead of accumulating; transistors make switches that other wires operate, gates make arithmetic, flip-flops make registers, and a vast array of numbered byte-boxes makes memory — into which, following the 1945 EDVAC draft, you put instructions as numbers, so a processor is nothing but fetch-decode-execute-advance on a program counter, and one machine ran one program while a human carried cards across a room. Making the loader a program gives you the resident monitor, the batch job, and spooling; making devices signal the processor instead of being polled gives you the interrupt, which is what asynchrony physically is; but a program that can overwrite the monitor makes all of it a convention, so hardware supplies a privilege bit — the kernel is a mode, not a process — with the system call as its single controlled door, and everything you have ever written passes through those roughly 350 entries. The kernel then needs a record of a running program, which is the process: identity, saved registers, an address space, descriptors, credentials, signals, a budget, a view. Saving and restoring registers is a context switch, costing microseconds once cache and TLB damage are counted, and a timer interrupt makes the taking-back involuntary, which is preemption; a scheduler then arbitrates by virtual runtime, and a monotonic clock read cheaply through the vDSO makes the accounting possible. Memory is shared not by giving each process a contiguous run — which fragments, caps size, and forbids sharing — but by cutting both sides into 4 KB pages mapped through a four-level table the MMU walks and the TLB caches, so that one hardware event, the page fault, serves demand loading, lazy allocation, copy-on-write, growable stacks, memory-mapped files and segmentation faults alike; an allocator carves those pages into objects and does not give them back, a garbage collector traces reachability above it, and when frames run out the kernel evicts, swaps, and finally sends an uncatchable SIGKILL that surfaces to you as exit code 137. Threads share the address space to get parallelism, which immediately reintroduces the interleaving that counter++ cannot survive, so compare-and-swap and futexes and lock ordering exist — but the original problem was waiting on devices, and thread-per-connection dies on the arithmetic at ten thousand clients, so select became poll became epoll, whose cost scales with events rather than connections, and libuv loops on it in phases with microtasks drained between every callback: that is the event loop, a cooperative scheduler running inside a preemptive one, which is why one slow function stalls every request in the process. Beneath it, a file is a byte sequence with its identity in an inode and its name merely a directory entry, reached through a descriptor that is an index into a per-process table, so redirection and pipes are just table rearrangement between fork and exec; and beneath that, write only reaches the page cache, so durability costs an fsync, which is the tax every write-ahead log in every database is paying, while filesystems journal their metadata and one of them, overlayfs, stacked read-only layers under a writable one, is exactly what a Docker image is. Give a process its own view of the process table, the mounts, the network and the user IDs, put it in a cgroup with a CPU weight and a memory ceiling, drop its capabilities, filter its syscalls, and execve its entrypoint — and you have a container, with no new kernel concept anywhere in it, only a hypervisor's hardware boundary left as the thing you buy when one shared kernel is not enough. Processes then talk: signals carry one integer and PID 1 ignores the ones it has no handler for, which is why your container survives docker stop for ten seconds; Unix sockets carry bytes and descriptors and verified credentials; and the kernel's TCP stack turns a lossy network into an ordered stream with two backlog queues, two independent windows, and a sixty-second TIME_WAIT that quietly explains connection pooling. All of it starts from a compiler and a linker that resolve symbols and patch addresses — the same job a bundler does for your modules — a dynamic linker that defers half of it to run time and thereby makes libc a deployment concern, an execve that replaces a program in place while descriptors and environment survive, a firmware-to-bootloader-to-kernel-to-init sequence that containers skip entirely, and an init system whose four jobs Kubernetes performs again across machines. You watch the running result through /proc, which is why every tool is a text parser, sample it with perf, trace it with eBPF running verified code inside the kernel that Node 3 said must never run there, and pay a boundary cost that rose in 2018 because of speculative execution and is now being designed around by io_uring's shared rings. Six forces produced all of it — sharing, protection, indirection, latency, the boundary, and compatibility — the ideas were essentially finished by 1970, and what has changed since is scale, cost, licences, and lawsuits.
