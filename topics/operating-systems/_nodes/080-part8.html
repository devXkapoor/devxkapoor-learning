PART VIII — FROM SOURCE TO RUNNING, AND FROM POWER-ON TO PID 1

Five nodes. Everything so far assumed a running program existed. This part builds one: source to object to executable, how it finds the library code it calls, what execve does with the file, how the machine gets from powered-off to running init, and what init then does. It also contains the most productive analogy-free parallel in this document — a JavaScript bundler is a linker, and every one of its concepts has an exact counterpart here.
